# Roadmap

This roadmap captures planned product and ecosystem work. It is a living document and will evolve as priorities and feedback change.

## Near Term

- Automate publishing with npm using GitHub Actions
- Improve API and types in the core library to provide more versatility
- Browser tool
- Routing support in React (react-router, TanStack Router, Next.js router)
- Vue and Angular packages

## Supporting Work

- Developer experience polish (errors, warnings, diagnostics)
- Documentation improvements and examples
- Performance and bundle-size benchmarks
- Testing utilities and harnesses
- Compatibility matrix across supported frameworks and versions
- Release process improvements (versioning, changelog, prerelease flow)
